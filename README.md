# Apex Luxury Motors

Apex Luxury Motors es una concesionaria de autos de lujo y alto rendimiento. Este sistema web es su vitrina digital: muestra el inventario de vehículos y permite gestionar las solicitudes de compra de los clientes.

## El negocio

Apex ofrece superdeportivos y deportivos de las principales escuelas del automovilismo (alemana, japonesa y estadounidense). El sitio atiende a dos tipos de usuario:

- **Clientes**, que exploran el catálogo, se registran y solicitan la compra del vehículo que les interesa.
- **El equipo de la concesionaria**, que mantiene el inventario al día y responde cada solicitud.

## Qué ofrece el sitio

**Para quien visita**
- Portada con carrusel de videos y presentación de la empresa: quiénes somos y qué hacemos.
- Catálogo de vehículos con filtros y el estado de cada unidad (Disponible o Vendido).
- Ficha de cada vehículo con galería de fotos, precio y especificaciones técnicas.

**Para el cliente registrado**
- Solicitud de compra de un vehículo disponible.
- Seguimiento de sus solicitudes, con la opción de cancelarlas.
- Perfil personal.

**Para el administrador**
- Gestión del inventario: alta, edición y baja de vehículos, y carga de fotos.
- Gestión de solicitudes: revisión y respuesta a cada solicitud de compra (aprobar o rechazar).

## Tecnologías

PHP con PDO, MySQL, HTML, CSS y JavaScript. Backend y frontend están separados en carpetas distintas.

Proyecto desarrollado para el curso de Ingeniería Web de la Universidad Tecnológica de Panamá.
